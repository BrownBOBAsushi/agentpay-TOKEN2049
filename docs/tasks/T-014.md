# T-014 — Security-paper texture for the cheque world
Milestone: M3 · Branch: feat/T-014-texture · Status: todo
Depends on: T-011..T-013 merged.

## Goal
The user found the pages "blunt — only plain blue". Make every cheque read as real **security paper**
(banknote/cheque printing), where each texture is an actual security feature, not decoration. Applies
to the shared `Cheque` (landing, `/receipt`, `/mandate`) and the page background. The updated
OWN-WORLD block in `.impeccable/surfaces/app-page-tsx.md` is binding.

## Approach (decided — builder implements, does not re-decide)
All textures are authored SVG/CSS in `src/web/` (no images, no new packages). Every layer sits under the
text with `aria-hidden`, and never drops value text below 4.5:1 contrast (measure on the darkest
texture spot behind values; state ratios in the build report).

1. **Rainbow printing** — each cheque's paper is a horizontal split-fountain blend:
   `#dfe9e1` (left) → `#e4ecef` (middle) → `#efe6d4` (right), as a soft linear gradient with a slight
   diagonal (≈100°). Page background stays plain `--paper`.
2. **Two-ink guilloche** — extend `guilloche.ts` to return two rosette path sets from the digest
   (second set seeded from the digest's second half, different lobe count), drawn in `#7fa79c`
   (sage-teal) and `#b39a6e` (bronze) at stroke 0.5–0.6px, overlapping in the right third. Keep the
   determinism and sensitivity tests; add one for the second set.
3. **Guilloche wave band** — inside the existing double frame, an 8–10px band of 3–4 interlaced sine
   strands (phase-shifted, sage-teal, 0.5px) running the full perimeter. Pure SVG, scales with the cheque.
4. **Microprint** — 4.5px Schibsted Grotesk caps, letter-spacing 0.06em, in `--ink-2`, repeating
   "AGENTPAY GUARD · SIGNED INTENT · " as (a) the signature line itself (replace the plain rule) and
   (b) one line along the inner top edge of the frame. Rendered as SVG `<text>` with `textLength` so it
   never wraps; `aria-hidden`.
5. **Pantograph field** — an SVG dot pattern (dot ≈0.6px, pitch ≈3px, `--ink` at 6% opacity) across the
   paper. Inside it, the word **COPY** is drawn with a *different* dot pitch (≈2px) so it is invisible
   at a glance on screen but readable when you look — shown **only on presented copies** (landing
   second screen, `/receipt` presented cheque). Signed cheques use the uniform field.
6. **Engraved seal** — a 56–64px fine-line medallion left of the "AgentPay Guard" legend: concentric
   rings + a radial line pattern + a small rosette, `--ink` at 0.5px. One shared SVG component.
7. **Paper grain** — `feTurbulence` (baseFrequency ≈0.9, 1 octave) at 3–4% opacity over each cheque.
   Must not animate; must not blur text.
8. Respect `prefers-contrast: more`: hide pantograph, grain, and microprint; keep rainbow and rosettes
   at lower opacity.

Keep everything else unchanged: stamp red only for REFUSE, OCR-B only for values (no ligatures),
one authored motion (stamp press), no gradients on text, no glass, no new colours beyond those above.
