# T-018 — `/demo` arena: replay S1 and S2 runs on the teller's desk
Milestone: M4 · Branch: feat/T-018-demo-arena · Status: todo
Depends on: T-017 merged (`RunTranscriptSchema` in `src/orchestrator/transcript.ts`). Decision: DEC-T14.
Design (binding): `PRODUCT.md`, `.impeccable/surfaces/app-page-tsx.md` (direction contract "Teller's desk").

## Goal
A `/demo` page that shows the two demo runs of the Orchestrator: S1 (honest page → Guard APPROVE → paid
over x402) and S2 (injected page → Guard REFUSE with Diff → no payment). It replays recorded preprod run
transcripts. It is the page a judge opens from the landing page and the video.

## Approach (decided — builder implements, does not re-decide)
- Data: `public/demo-runs/s1.json` and `public/demo-runs/s2.json`, loaded at build time (import or `fs` in a
  server component) and parsed with `RunTranscriptSchema`. Builder writes placeholder files with
  `"recorded": false` built from the T-017 test data; orch replaces them with real runs later. When
  `recorded` is false the page shows a clear "Example run — not yet recorded on preprod" note.
- Layout on the desk: two buttons/tabs "S1 — honest offer" and "S2 — injected offer". The selected run shows:
  1. the offer page as a paper note; for S2 the injected line is visible and marked with the red-pencil ring
     (from `injectedExcerpt`);
  2. a run log (OCR-B, paper tape or ledger style) whose lines appear in order on "Replay" (about 400 ms
     each); with `prefers-reduced-motion` all lines show at once; "Replay" again restarts;
  3. the outcome: S1 → "PAID" with the Cardanoscan preprod link `https://preprod.cardanoscan.io/transaction/
     <txHash>` and a link to `/receipt/<taskId>`; S2 → RETURNED, the Diff rows (`field / signed / presented`),
     "No payment made", link to `/receipt/<taskId>`.
- Reuse existing desk components (`src/web/Desk.tsx`, `PaperObject`, `Stamp`, rings) — no new visual language.
- Landing: add one link to `/demo` beside the existing calls to action (no other landing change).
- Accessibility: log is a real ordered list in DOM; buttons are `<button>` with `aria-pressed`; text on desk
  ≥ 4.5:1. Mobile 390 px: single column, no horizontal scroll.

## Files allowed
`app/demo/**`, `public/demo-runs/**`, `src/web/**` (new demo components; existing ones presentation-only),
`app/page.tsx` (one link only), `docs/tasks/T-018.build.md`.

## Acceptance criteria
- [ ] Render tests: S1 shows PAID + tx link + receipt link; S2 shows RETURNED + every Diff row + "No payment
      made"; `recorded:false` shows the example note; invalid transcript JSON fails the build/test clearly.
- [ ] `npm run typecheck && npm run lint && npm test` green. (orch runs `npm run build` and browser checks
      at 1440×900 and 390×844.)

## Out of scope
Live runs from the browser, new data sources, changes to the Orchestrator, deploy.
