Fix all, in one round:
1. Stamp must render visible by default (no JS, print, full-page capture). The press animation is only an enhancement that starts after hydration when the stamp enters the viewport (craft floor: motion from an already-visible default). Reduced-motion unchanged.
2. Stamp reason line is illegible (displacement filter mangles it). Set the reasons in OCR-B ≥14px, outside the displacement filter, still inside the stamp box.
3. The presented copy must show what the agent presented: payee and amount lines carry the presented values (struck through, ink, with a small `--stamp` margin mark "MUST NOT"), and below each the signed value as a quiet annotation "signed: …" in `--ink-2`, smaller. Today the signed value reads as the main value.
4. Amount reads in human units: main "2 tADA" (presented "9 tADA"), atomic "2,000,000 lovelace" small in OCR-B under it. Use the same string arithmetic as T-013 (6 decimals, no floats).
5. Guilloche is a wave curtain, not safety paper. Make it a closed rosette (hypotrochoid/epitrochoid family, 40–70 strokes) centred in the right third, plus a fine border band inside the cheque frame; keep it digest-seeded. The presented copy uses the proposalDigest so its rosette visibly differs from the signed cheque. Keep `guilloche.ts` tests (determinism + sensitivity).
6. Remove "Copy signature" and "View full signature" from the presented copy; it shows the signature line only.
7. Remove the separate red "Verdict: REFUSE" line under the presented copy; the stamp carries the verdict. Keep the one explanatory sentence.
8. Back of the cheque: the CLEARED stamp floats alone bottom-left. Move the outcome marks into endorsement 3 as a pair, small: CLEARED "matching proposal" and RETURNED "forged proposal".
9. Mobile: the presented copy has a large empty gap below the signature controls (reserved stamp space). On narrow screens the stamp sits in flow after the amount box; no empty band.
