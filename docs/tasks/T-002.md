# T-002 — Mandate schema, JCS, Mandate Digest
Milestone: M1 · Branch: feat/T-002-mandate · Status: done
Depends on: T-001 merged.

## Goal
Define the **Mandate** as a zod schema and compute the **Mandate Digest**
(`SHA-256(prefix ‖ JCS(mandate))`, see `CONTEXT.md`). Every later guard-core part uses these
types and this digest.

## Approach (decided — builder implements, does not re-decide)
- `src/guard/mandate.ts`: zod schema `MandateSchema`, strict (no extra keys):
  - `v: 1` (literal), `network: "cardano:preprod"` (literal — preprod only),
  - `payer`: bech32 string starting `addr_test1`,
  - `payee`: non-empty string (a bech32 `addr_test1…` address or a Masumi `agentIdentifier`),
  - `asset`: `"lovelace"` or `"<56 hex policyId>.<0–64 hex assetName>"` (same format as x402
    `asset`, `docs/research/X402-CARDANO-DIGEST.md` §1),
  - `amount`: positive decimal integer string in atomic units (regex `^[1-9][0-9]*$`), never a number,
  - `expiry`: integer, unix seconds,
  - `nonce`: 32 hex chars (16 random bytes),
  - `purpose`: string, 1–280 chars.
  Export `type Mandate = z.infer<typeof MandateSchema>` and `parseMandate(x): Mandate` (throws a
  typed `MandateParseError`).
- `src/guard/jcs.ts`: `jcs(value): string` using the `canonicalize` npm package (RFC 8785).
- `src/guard/digest.ts`: `MANDATE_PREFIX = "agentpay:mandate:v1\n"`;
  `mandateDigest(m): string` = lowercase hex SHA-256 of UTF-8 `MANDATE_PREFIX + jcs(m)`.
  Use `node:crypto`. Pattern from `docs/research/X402-CARDANO-DIGEST.md` §6c (Masumi terms digest).
- Export the public API from `src/guard/index.ts`.

## Files allowed
