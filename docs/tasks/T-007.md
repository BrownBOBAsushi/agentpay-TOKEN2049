# T-007 — Core client and free Guard Task Worker (rehearsal)
Milestone: M2 · Branch: feat/T-007-worker-free · Status: todo
Depends on: T-006 merged.

## Goal
A Worker that finds a `READY` Guard Check **Task** for our **Coworker**, starts it, runs the
**Guard Check**, and completes the Task with the signed **Guard Receipt** as the result — with no
payment. This is the "free rehearsal Task" in `docs/PLAN.md` M2.

## Approach (decided — builder implements, does not re-decide)
- Transport and endpoints: DEC-T09. Core base URL from `SOKOSUMI_API_URL` without the `/v1`
  suffix confusion: use origin `https://api.preprod.sokosumi.com` and paths starting `/v1/…`.
  Refuse to start if the origin is not `api.preprod.sokosumi.com` (preprod only).
- `src/worker/config.ts`: read and validate env with zod: `SOKOSUMI_API_URL`,
  `SOKOSUMI_COWORKER_API_KEY`, `SOKOSUMI_COWORKER_ID`, `DATABASE_URL`, `GUARD_SIGNING_KEY`,
  `GUARD_ADDRESS` (addr_test1…), `POLL_INTERVAL_MS` (default 10000; Sokosumi asks ≥ 10 s,
  `MASUMI-DIGEST.md` §7). Never log values. Loading `.env.local` for local runs: use Node
  `--env-file-if-exists=.env.local` in the `worker` npm script; do not read env files in code.
- `src/worker/core.ts`: `createCoreClient({origin, apiKey, fetch})` with `me()`,
  `listReadyTasks(coworkerId)` (`GET /v1/tasks?coworkerId=…&status=READY`), `getTask(id)`,
  `postEvent(id, body)`. `Authorization: Bearer`, `redirect: "error"`, 30 s timeout. Map HTTP
  4xx to `SafeToRetryError` only for GET; a failed POST is uncertain (do not mark safe).
- `src/worker/guard-task.ts`: pure `runGuardTask({taskId, description, nowSec, store, guardKey})`:
  parse description as JSON `{mandateBundle, proposal}` (DEC-T11; parse failure → REFUSE
  `PROPOSAL_INVALID` receipt, not a crash) → `nonceUsed = store.isNonceUsed(...)` →
  `guardCheck` → on APPROVE `store.consumeNonce(...)` (false → change Verdict to REFUSE
  `NONCE_REUSED`) → `signReceipt` with `proposalDigest`, `mandateDigest`, `taskId`, `ts` →
  return the result string `JSON.stringify(signedReceipt)` (exact bytes are later hashed).
- `src/worker/free-flow.ts`: per Task, journal stages with `store.once` keys
  `{taskId, eventId: "-", action}`: `start` (post `{status:"RUNNING"}`) → `check` (runGuardTask,
  save result in journal) → `complete` (post `{status:"COMPLETED", comment: result}`).
  A Task already `RUNNING` with no journal is left alone and logged (not ours to resume).
- `src/worker/index.ts`: load config, migrate, single-process loop: list READY tasks → free-flow
  each → sleep `POLL_INTERVAL_MS`. Log one line per stage with taskId only. Exit on SIGTERM
  between Tasks.
- Paid flow is T-008: leave a clear `TODO(T-008)` branch point, no paid code.

## Files allowed
`src/worker/**`, `package.json` (scripts only), `.env.example` (add `SOKOSUMI_COWORKER_ID`,
`POLL_INTERVAL_MS` placeholders only).

## Acceptance criteria
- [ ] Unit tests with a fake `fetch` and PGlite: READY Task → exactly one RUNNING post, one
      COMPLETED post whose comment verifies with `verifyReceipt` and `GUARD_ADDRESS`.
- [ ] Restart after `check` (journal has result) → no second check, one COMPLETED post.
- [ ] Crash after RUNNING post but before marking done → `UncertainSideEffectError`, no repost.
- [ ] S2 description (injected payee + amount) → completed with REFUSE receipt and a 2-field Diff.
- [ ] Same Mandate in a second Task after APPROVE → REFUSE `NONCE_REUSED`.
- [ ] Config refuses a non-preprod origin and a mainnet `GUARD_ADDRESS`.
- [ ] `npm run typecheck && npm run lint && npm test` green.
- [ ] (orch, live, after merge) one rehearsal Task completes on preprod; Task ID in `docs/EVIDENCE.md`.
