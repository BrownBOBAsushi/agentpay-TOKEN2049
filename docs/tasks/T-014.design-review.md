# T-014 — orch design review (round 1, batched)
Screens: desktop 1440×900 fold + presented copy, 2× zoom of the frame, mobile 390×844 (local `next start` of 19a222c).
Holds: rainbow tint, wave band, frame microprint (crisp at 2×), engraved seal, pantograph field, grain. Clearly richer.

Fix all, in one round:
1. Remove the hard-edged paper rectangles behind value text (`cardano:preprod`, memo, void after, signature, MICR band). They read as highlighted text. Instead keep contrast by keeping texture out from under text: mask the rosettes (SVG mask or `mask-image`) with soft-edged (≈8px feather) cut-outs behind value rows that overlap a rosette; no underlay where no rosette overlaps. The amount box keeps its own solid fill (it is a box). Re-state the measured contrast.
2. Rosettes must read as engraved lines, not a filled blob: fewer strokes per plate (24–36), larger spread between inner and outer radius, bronze lighter (`#c9b28a`) at 0.45px, sage-teal at 0.45px, each plate ≤0.55 opacity; individual lines must be distinguishable at 1×.
3. COPY pantograph must be discernible on presented copies at 1× when you look: COPY dots at ≈11% opacity vs field 6%, letters ≈40% of cheque height, placed left-centre behind the payee/memo block (masked out behind value text per item 1). Still absent on signed cheques.
4. Mobile: rosette sits as a small stain beside the memo. On widths <640px render one plate only, centred behind the amount box at ≤0.35 opacity, or omit it.

Re-run `npm run typecheck && npm run lint && npm test && npm run build`; append "Design round 1" (≤5 lines) to T-014.build.md.
