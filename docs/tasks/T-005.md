# T-005 — Guard Receipt sign and verify
Milestone: M1 · Branch: feat/T-005-receipt · Status: todo
Depends on: T-004 merged.

## Goal
Make the **Guard Receipt**: the signed record of a **Verdict**, signed by the **Guard Key**.
Its hash becomes the Task result hash on chain (M2). Anyone can verify it with the Guard address.

## Approach (decided — builder implements, does not re-decide)
- `src/guard/receipt.ts`:
  - `GuardReceipt = {v:1, verdict, reasons, diff, mandateDigest, proposalDigest, taskId, ts}`
    (`ts` = unix seconds, passed in, no clock in guard-core).
  - `proposalDigest(p)` = hex SHA-256 of UTF-8 `"agentpay:proposal:v1\n" + jcs(p)`.
  - `receiptDigest(r)` = hex SHA-256 of UTF-8 `"agentpay:receipt:v1\n" + jcs(r)`.
  - `signReceipt(r, guardKey: {privateKeyHex, address}) → {receipt, coseSign1, coseKey, guardAddress, digest}`
    using `COSE.SignData.signData` over UTF-8 `jcs(r)` (same primitive as T-003).
  - `verifyReceipt(signed, expectedGuardAddress): boolean`, never throws; reuses the T-003
    COSE_Key checks.
- The key is a parameter. guard-core does not read env. Add to `.env.example`:
  `GUARD_SIGNING_KEY=` (hex Ed25519 private key, preprod only) and `GUARD_ADDRESS=` (addr_test1…),
  with a comment that the Guard Key holds no funds and is separate from every wallet.
- Never log the key. Tests use a fixed test-only seed.

## Files allowed
`src/guard/receipt.ts`, `src/guard/cip8.ts` (extract shared COSE_Key check only),
`src/guard/index.ts`, `src/guard/*.test.ts`, `src/guard/fixtures/**`, `.env.example`.

## Acceptance criteria
- [ ] Sign then verify → `true` for APPROVE and REFUSE receipts.
- [ ] Changed `verdict`, changed Diff, or other `expectedGuardAddress` → `false`.
- [ ] `receiptDigest` pinned test vector for a fixed receipt.
- [ ] `grep -rn "GUARD_SIGNING_KEY" src` finds no `console.` line.
- [ ] `npm run typecheck && npm run lint && npm test` green.

## Out of scope
`submitResultHash` / MIP-004 hashing and the worker (M2), Receipt viewer page (M3).
