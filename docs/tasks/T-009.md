## Goal
Run the Worker, MPS, and Postgres hosted, so a Task runs with the laptop closed (`docs/PLAN.md`
M2, DEC-T05). Judges need a hosted demo.

## Approach (decided — builder implements, does not re-decide)
- Builder scope is repo-side only: a `Dockerfile` (or Railway Nixpacks config) for the Worker
  that runs `node --import tsx src/worker/index.ts`, Node 24, no env files in the image.
- orch + human do the Railway side: project, Postgres plugin, MPS service from
  `masumi-network/masumi-payment-service`, env vars in Railway (never in git), and update
  `docs/OPS.md` "Where things run" and "Secrets map".
- Moving MPS changes `MPS_BASE_URL` to an https URL; T-008 config already accepts https.
- Web stays on Vercel. This card does not touch the Vercel project. Vercel rule
  (`docs/OPS.md`): keep `https://agentpay-guard-cardano.vercel.app` and
  `/examples/guard-receipt-refuse.json` alive.

## Files allowed
