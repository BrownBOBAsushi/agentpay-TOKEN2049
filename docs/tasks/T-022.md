# T-022 — `/store` live mode: real x402 payment on Cardano after a Guard APPROVE
Milestone: M4+ · Branch: feat/T-022-store-pay · Status: todo · Base: T-021 merged (orch gives the hash)
Decision: DEC-T18. Reuse: `src/orchestrator/payment.ts` (+ `journal.ts`), T-021 hire/poll, T-020 agent.
Deps: orch installs `@x402/next@2.26.0` + `@x402/paywall@2.26.0` (exact pins) before you start.

## Goal
With the private link, the presenter turns the injection OFF, clicks Buy, and sees in one flow: agent reads
the latte page → the latte route answers **402 PAYMENT-REQUIRED** → Spend Proposal → Guard hired on Sokosumi →
verified **APPROVE** Receipt → **x402 payment of 6.5 tADA on Cardano preprod** → tx hash + Cardanoscan link.

## Approach (decided)
- **Seller route** `GET /api/store/latte`: x402-paid with `withX402` (`@x402/next`), `x402ResourceServer` +
  `HTTPFacilitatorClient({url: X402_FACILITATOR_URL || hosted preprod})` + `ExactCardanoScheme` (server).
  `accepts: {scheme:"exact", network:"cardano:preprod", price:{amount:"6500000", asset:"lovelace"},
  payTo: <store address = the store Mandate payee constant>, maxTimeoutSeconds:600, extra:{confirmationPolicy:
  {l1Confirmations:0}}}`. Handler returns `{item:"Latte", store:"The Corner Store"}`. Public (unpaid GET → 402).
- **Live mode gate:** env `STORE_LIVE_KEY` (≥ 32 chars). Page reads `?live=`; every live API call sends it in a
  header `x-store-live-key`; server compares with `crypto.timingSafeEqual`. Wrong/missing → public mode.
  Never echo the key; never log it.
- **Live honest path** (injection OFF or parses to the store + 6.50): the agent GETs the absolute
  `/api/store/latte` URL of this deployment, decodes the 402 (`x402HTTPClient.getPaymentRequiredResponse`),
  proposal = `accepts[0]` → local `guardCheck` → **hire the Guard** (T-021 path, also for APPROVE in live mode)
  → poll until the verified Receipt (`loadReceipt`, must be APPROVE with matching taskId/proposal/mandate
  digests) → `POST /api/store/pay {taskId}` (live key required) runs the payment with the T-017/T-019 code:
  `toClientCardanoSigner({mnemonic: ORCHESTRATOR_WALLET_MNEMONIC, provider: Blockfrost preprod
  BLOCKFROST_API_KEY_PREPROD})`, spend controls = exactly the approved asset/amount, fresh requirements digest
  equal to the approved one, built TTL ≤ Mandate expiry, same signed bytes on retry, chain confirmation on
  `nonce_not_on_chain`/timeout. Journal at `/tmp/agentpay-store-journal.json` keyed `{taskId, eventId, "pay"}`
  (a second pay for the same Task returns the saved result). `export const maxDuration = 300`.
- **Live attack path** (injection ON): unchanged from T-021 (hire → REFUSE → no payment).
- **Mandate in live mode:** a "Load signed Mandate (bundle.json)" file input; the server re-verifies it
  (`verifyMandate` ok, payee = store address, asset lovelace, amount 6500000) and uses it for this run instead
  of the fixture. Invalid → clear error, nothing hired. Public mode never accepts uploads.
- **UI:** log lines "402 PAYMENT-REQUIRED: 6.5 tADA to The Corner Store", "Guard hired on Sokosumi — Task …",
  "Signed Receipt verified: APPROVE", "Paying over x402 on Cardano preprod…", "Paid: <tx hash>". Outcome: the
  CLEARED desk scene + "Paid on Cardano preprod" with `https://preprod.cardanoscan.io/transaction/<hash>`,
  the Sokosumi Task link and `/receipt/<taskId>`. A small "LIVE" tag when live mode is on.
- Env (server only): `ORCHESTRATOR_WALLET_MNEMONIC`, `BLOCKFROST_API_KEY_PREPROD`, `X402_FACILITATOR_URL`,
  `STORE_LIVE_KEY` + T-021's. Add names to `.env.example`. Missing → live mode off.
