# T-001 — Repo scaffold
Milestone: M0 · Branch: feat/T-001-scaffold · Status: todo

## Goal
Make an empty but working TypeScript project that matches the layout in `ARCHITECTURE.md`
"Components", so later tasks only add code.

## Approach (decided — builder implements, does not re-decide)
- One npm package at the repo root. Node >= 24 in `engines`. TypeScript strict.
- Next.js (App Router) in `app/` with one placeholder page "AgentPay Guard".
- Empty entry files: `src/guard/index.ts`, `src/worker/index.ts`,
  `src/orchestrator/index.ts`, `src/demo-seller/index.ts`.
- vitest with one passing test in `src/guard/index.test.ts`.
- ESLint (Next default flat config). Scripts: `dev`, `build`, `typecheck`, `lint`, `test`,
  `worker` (`tsx src/worker/index.ts`), `orchestrator`, `demo-seller`.
- Do not add Cardano, Masumi, or x402 packages yet. They come with their own tasks.

## Files allowed
`package.json`, `package-lock.json`, `tsconfig.json`, `next.config.ts`, `eslint.config.mjs`,
`vitest.config.ts`, `app/**`, `src/**`, `CLAUDE.md` (Commands section only), `README.md`
("Run it" section only).

## Acceptance criteria
- [ ] `npm install` from a clean clone works.
- [ ] `npm run typecheck && npm run lint && npm test` green.
- [ ] `npm run build` succeeds.
- [ ] `CLAUDE.md` "Commands" lists every script with one line each.

## Out of scope
Any feature code. `.agents/`, `.claude/`, `docs/` (except your build report).
