# T-003 — CIP-8 Mandate signature verify
Milestone: M1 · Branch: feat/T-003-cip8-verify · Status: todo
Depends on: T-002 merged. Real-wallet fixture depends on SPIKE S3 (see below).

## Goal
Verify a **Mandate** signature cryptographically (CIP-8 COSE_Sign1, Ed25519) and prove the
signer is `mandate.payer`. This is a hard rule: never a UI-only check.

## Approach (decided — builder implements, does not re-decide)
- Add `@evolution-sdk/evolution` at one exact pinned version. Before you write code, read its
  `.d.ts` for `COSE.SignData.verifyData`, `COSE.SignData.signData`, `Address`, `Credential`
  and confirm the shapes match `docs/research/X402-CARDANO-DIGEST.md` §6c. If they differ, stop
  and write the question in the build report.
- `src/guard/bundle.ts`: zod `MandateBundleSchema` = `{mandate, coseSign1, coseKey, payerAddress, digest}`
  (hex strings; `mandate` uses `MandateSchema` from T-002). This is the bundle from
  `ARCHITECTURE.md` step 1.
- `src/guard/cip8.ts`: `verifyMandate(bundle): VerifyResult` where
  `VerifyResult = {ok: true} | {ok: false, reason: "SIG_INVALID" | "SIGNER_MISMATCH" | "DIGEST_MISMATCH" | "BUNDLE_INVALID"}`.
  Never throws. Steps:
  1. Parse the bundle (fail → `BUNDLE_INVALID`).
  2. `bundle.digest` must equal `mandateDigest(bundle.mandate)` (fail → `DIGEST_MISMATCH`).
  3. `payerAddress` must equal `mandate.payer` and be a key-hash address (fail → `SIGNER_MISMATCH`).
  4. Payload bytes = UTF-8 `jcs(mandate)` (DEC-T04). Validate the COSE_Key: OKP, EdDSA,
     Ed25519, 32-byte `x`, no `d`. Reject `hashed:true`. Then `COSE.SignData.verifyData(...)`
     bound to the payer payment key hash (fail → `SIG_INVALID`).
- Test fixtures: generate a deterministic test key in the test (fixed 32-byte seed, test only,
  never a real wallet key) and sign with `COSE.SignData.signData`. Save the produced bundle to
  `src/guard/fixtures/bundle.valid.json` so the test does not depend on signing.
- Real wallet fixture: add `it.skip("verifies a Lace/Eternl signData bundle", …)` that loads
  `src/guard/fixtures/bundle.wallet.json` when it exists. `orch` will add the file after S3.

## Files allowed
`src/guard/bundle.ts`, `src/guard/cip8.ts`, `src/guard/index.ts`, `src/guard/*.test.ts`,
`src/guard/fixtures/**`, `package.json`, `package-lock.json`.

## Acceptance criteria
- [ ] Valid fixture → `{ok:true}`.
- [ ] Each tamper is caught with the right reason: changed `amount` (→ `DIGEST_MISMATCH`, and with
      a recomputed digest → `SIG_INVALID`), different `payerAddress` (→ `SIGNER_MISMATCH`),
      flipped signature byte (→ `SIG_INVALID`), `hashed:true` (→ `SIG_INVALID`), junk hex (→ `BUNDLE_INVALID`).
- [ ] No private key or seed is logged; the test seed is labelled test-only.
- [ ] `npm run typecheck && npm run lint && npm test` green.
